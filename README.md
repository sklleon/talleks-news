# Новости Таллекс Какао — статический сайт

Раздел новостей и экспертных материалов, который заменяет публикацию в Поток Tilda.
Причина переезда и полный план — в [plans/2026-07-21-новости-на-своём-хостинге.md](../plans/2026-07-21-новости-на-своём-хостинге.md).

## Как устроено

- Контент — markdown-файлы в `content/news/`, по файлу на материал.
- Next.js собирает статику (`output: 'export'`), результат — папка `out/`.
- Публикация новости = добавление md-файла и пересборка. Никаких логинов и сессий.

## Команды

```bash
npm install       # разово
npm run dev       # локальная разработка, http://localhost:3000
npm run build     # сборка статики в out/ + генерация rss.xml
```

## Структура

| Путь | Что там |
|---|---|
| `content/news/*.md` | материалы: фронтматтер + текст |
| `app/page.tsx` | лента материалов |
| `app/[slug]/page.tsx` | страница материала |
| `app/rubrika/[rubric]/page.tsx` | лента по рубрике |
| `app/sitemap.ts`, `app/robots.ts` | карта сайта и robots, собираются из контента |
| `tools/generate-rss.mjs` | rss.xml после сборки |
| `tools/export_from_tilda.py` | разовая выгрузка материалов из Потока Tilda |
| `redirects.json` | карта «прежний адрес → новый» для 301 на Cloudflare |

## Фронтматтер материала

```yaml
---
title: "Заголовок"
date: 2026-07-08
date_estimated: false   # true — дату не удалось установить точно, нужна ручная правка
rubric: "Ассортимент"   # одна из пяти рубрик, может быть пустой
description: "Описание для выдачи и соцсетей, до 160 знаков"
cover: "https://..."    # обложка, может быть пустой
source_url: "https://talleks.ru/news/..."  # прежний адрес на Tilda, для редиректа
---
```

Рубрики: Новое поступление, Спецпредложение, Ассортимент, Сертификация, Рынок.

## Про обложки

Обложки перенесённых материалов пока ссылаются на CDN Tilda. После удаления постов
из Потока эти файлы могут стать недоступны — вопрос хранения картинок решается
отдельно (в git они не коммитятся, см. CLAUDE.md).
